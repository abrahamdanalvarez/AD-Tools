| D23 | 2026-11-26 | axe-core accessibility checks in e2e for light/dark × desktop/mobile. Must be 0 violations. | Holds the accessibility bar from the start. | Accepted |

| D29 | 2026-11-26 | Footer links without a real page (About, Privacy Policy, Terms, Cookies, Contact, Report a Bug, Request a Tool, GitHub) stay in `src/site.ts` with `href: null` and are hidden until they exist. | No broken links. Legal pages and contact details need owner input. | Accepted |
| D30 | 2026-11-26 | Workers are the default. When a browser lacks a worker feature (OffscreenCanvas in Playwright's Windows WebKit), the same code runs on the page via `runCancellable`. Feature checks, not `instanceof`, inside shared code. | Keeps the tool working everywhere without a second implementation. | Accepted |
| D31 | 2026-11-26 | E2E runs every spec in Chromium. Tool specs also run in Firefox and WebKit. A tool is `verified` only after passing all three. | Catches engine differences (WebP encoding, OffscreenCanvas) before release, while keeping the suite fast. | Accepted |
| D32 | 2026-11-26 | PDF engines: pdf-lib 1.17.1 (MIT) for editing, pdfjs-dist 6.5.438 (Apache-2.0) for rendering and text, qpdf 12.2.0 via @neslinesli93/qpdf-wasm 0.3.1 (Apache-2.0 / ISC) for AES-256 encryption, fflate 0.8.3 (MIT) for ZIP downloads. BentoPDF (AGPL-3.0) was studied as a reference only, and none of its code is used. | Permissive licences, browser-only, proven. AGPL code would force the project licence. | Accepted |
| D33 | 2026-11-26 | pdf.js uses the **legacy** build. | The modern build calls `Map.prototype.getOrInsertComputed` and `Math.sumPrecise` directly, and not every browser Privora supports has them yet. | Accepted |
| D34 | 2026-11-26 | pdf.js data files (CMaps, standard fonts, ICC, decoder WASM) are self-hosted at `/vendor/pdfjs/`. QuickJS (the PDF scripting engine) is not shipped. Scripting, annotation and form layers and XFA are never enabled. | No requests to other origins. Embedded PDF JavaScript can never run. | Accepted |
| D35 | 2026-11-26 | Every PDF tool shares one config-driven `PdfToolShell` and one worker (`runOp`). A tool is a config entry plus a registry entry. | 31 tools stay maintainable by one developer, with one place to fix behaviour. | Accepted |
| D36 | 2026-11-26 | Repair PDF uses pdf-lib's lenient parser, then re-saves without object streams and re-opens the result strictly to verify it. | The qpdf WASM build exits on damaged cross-reference tables instead of rebuilding them. | Accepted |
| D37 | 2026-11-26 | Unlock PDF needs the real password. Encryption is detected with pdf-lib, and a failed qpdf decrypt is reported as a wrong password. Empty passwords are refused, so owner-restricted files cannot be unlocked without their password. | The wasm build's `--is-encrypted` always returns 2 and its error text bypasses the print hooks. The spec requires a valid supplied password. | Accepted |
| D38 | 2026-11-26 | Compress PDF only re-encodes large baseline JPEG photos (8-bit gray or RGB, no masks or Decode arrays), strips EXIF, scales the longest side down to 3000, 2000 or 1400 px by level, and keeps an image only when it is at least 10% smaller. Text, vectors, links and tags are untouched. If the file doesn't shrink, the original is returned and the user is told. | Fidelity: no silent rasterising, and the quality trade-off is disclosed. | Accepted |
| D39 | 2026-11-26 | OCR PDF and PDF Annotation stay `planned` (hidden). | OCR needs self-hosted Tesseract language data and a no-persistence setup (tesseract.js caches in IndexedDB by default). A reliable annotation editor is a project of its own. Neither is ready to verify. | Accepted |
| D40 | 2026-11-26 | Visual Signature is labelled as an image of a signature, not a cryptographic digital signature, in the tool, its notes and FAQ. | The spec requires the distinction, and users must not mistake it for PAdES. | Accepted |
| D41 | 2026-11-26 | Vite stubs the Node built-ins (`fs`, `path`, `crypto`) that qpdf-wasm's Emscripten loader imports for its Node path, in the app and worker builds. | The Node path never runs in a browser. The stub removes build warnings and dead shims. | Accepted |
| D42 | 2026-11-26 | Shared UI fixes from Phase 04 a11y testing: alert body text uses `text-foreground/85`, inactive tabs `text-foreground/75`, the settings fieldset is a `minmax(0,1fr)` grid, page thumbnails are fluid. | axe found contrast of 4.34–4.37 and a 131 px mobile overflow. | Accepted |
