## Logo

An original P monogram. The bowl is round. The stem ends in a soft shield point, a quiet nod to protection without being a padlock or a badge. The counter (the space inside the P) is filled with the accent colour: *your file, kept inside*.

Design notes:
- A white P on a blue tile reads as the international **parking sign**, so it was rejected. The app icon uses the mark on the dark secondary colour instead.
- A literal shield badge was tried and rejected as a generic security look.
- The wordmark is Plus Jakarta Sans Bold converted to outlines, so the SVGs need no font.

### Usage rules

- Leave clear space around the logo at least the width of the P's stem.
- Minimum size: mark 16 px, horizontal lockup 80 px wide.
- Don't recolour, stretch, outline, add effects, or put the light logo on a dark background (use the dark variant).

## Typography

| Role | Font | Token | Package |
|---|---|---|---|
| Headings | Plus Jakarta Sans (variable) | `font-heading`, applied to h1–h4 | `@fontsource-variable/plus-jakarta-sans` |
| Body | Inter (variable) | `font-sans` (default) | `@fontsource-variable/inter` |
| Code | JetBrains Mono (variable) | `font-mono`, applied to code/kbd/pre | `@fontsource-variable/jetbrains-mono` |

All are OFL-1.1 and self-hosted from `dist/assets`. Each script subset loads only when a page uses those characters. No Google Fonts requests.

Scale: page h1 `text-4xl`/`sm:text-5xl` bold; section h2 `text-2xl` semibold; card h3 `text-base` semibold; body `text-base`/`text-sm`; meta `text-xs`. Avoid oversized display type.

## Spacing, radius, shadow

- Containers: `max-w-6xl`, `px-4 sm:px-6`. Sections: `py-12`.
- Radius: `md` 0.5rem (controls), `lg` 0.75rem (icon tiles, alerts), `xl` 1rem (cards).
- Shadows: `shadow-xs` default and `shadow-md` on hover. Shadows are tinted with slate in light mode and pure black in dark mode.
- Motion: colour and shadow transitions only. `prefers-reduced-motion` turns animations off.

## Theme

- Default: follows the system (`prefers-color-scheme`), with nothing stored.
- The toggle stores `privora-theme` = `light` | `dark` in `localStorage`. That's the only stored value, and it's allowed by `PRIVACY.md`.
- `public/theme-init.js` applies the class before first paint (no flash). It's a static file, not inline, so a strict CSP can allow it.
